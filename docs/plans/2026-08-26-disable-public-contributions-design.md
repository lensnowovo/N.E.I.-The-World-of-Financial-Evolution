# 关闭公开投稿设计

## 决策

N.E.I. 当前阶段定位为由管理员维护的 PEVC Skill Library 与 MCP 分发平台。普通用户继续使用浏览、搜索、复制、收藏、MCP Token 和个人收藏库，但不再直接向网站投稿或编辑公开内容。评论、点赞和关注继续保持关闭。

管理员保留新增、编辑、审核和下架内容的能力；历史投稿与收藏数据不删除。

## 实现边界

- 服务端拒绝非管理员调用投稿、投稿附件上传和发布辅助接口。
- `/publish` 与内容编辑页仅管理员可访问。
- 公共导航、首页、任务页、控制台和侧边工作台不再邀请普通用户投稿。
- 收藏及 MCP 的 `favorite_skill`、`unfavorite_skill`、`list_my_skills` 保持可用。
- GitHub Issue / Pull Request 仍可用于提供内容线索，由管理员审核后入库。

## 验收

- 普通用户无法通过直接请求绕过 UI 创建或编辑内容。
- 管理员仍可使用原有发布和编辑流程。
- 首页及登录注册页面不再宣称可评论或公开投稿。
- 历史内容、收藏和 MCP 调用不受影响。
